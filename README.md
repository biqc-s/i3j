# i3j.io — الموقع الشخصي + السيرة الذاتية (ATS)

موقع شخصي ثنائي اللغة (عربي / إنجليزي) لـ **سعيد أحمد جهاش**، منشور على [i3j.io](https://i3j.io) عبر GitHub Pages.
يولّد الموقع **سيرة ذاتية متوافقة مع أنظمة ATS** بالعربية أو الإنجليزية من نفس البيانات، ويمكن لأي زائر طباعتها أو حفظها PDF.

---

## ✏️ كيف أحدّث المحتوى؟

**كل المحتوى في ملف واحد:** [`data/profile.js`](data/profile.js)
عدّله، ثم ادفع التعديل (commit + push) إلى `main`. يتحدث الموقع والسيرة الذاتية بالعربي والإنجليزي تلقائياً.

### أمثلة سريعة

**إضافة وظيفة جديدة:** أضفها في **أول** قائمة `experience`، فالترتيب من الأحدث إلى الأقدم:

```js
{
    role:     { en: 'Director of Digital Transformation', ar: 'مدير التحول الرقمي' },
    org:      { en: 'Company Name', ar: 'اسم الجهة' },
    location: { en: 'Riyadh', ar: 'الرياض' },        // اختياري
    start: '2025-01', end: null,                      // null = حتى الآن
    tag:  { en: 'Leadership', ar: 'قيادة' },
    icon: 'fa-briefcase',                             // من fontawesome.com/icons
    points: [
        { en: 'Led ... resulting in 30% ...', ar: 'قاد ... مما أدى إلى 30% ...' }
    ]
},
```

**إضافة مشروع:**

```js
{
    title:       { en: 'Project name', ar: 'اسم المشروع' },
    description: { en: '...', ar: '...' },
    icon: 'fa-lightbulb',
    tags: ['AI', { en: 'Government', ar: 'حكومي' }],
    url: 'https://...',          // اختياري: يضيف رابطاً للبطاقة
    featured: true,              // اختياري: إطار ذهبي
    award: { en: 'Winner', ar: 'فائز' }   // اختياري
},
```

**إضافة شهادة:**

```js
{ icon: 'fa-certificate', name: { en: 'CISA', ar: 'CISA' }, issuer: 'ISACA', year: 2025 },
```

### خيارات مفيدة

| الخيار | ماذا يفعل |
|---|---|
| `cv: false` | يخفي العنصر من السيرة الذاتية فقط، ويبقى ظاهراً في الموقع |
| `site: false` | يخفي العنصر من الموقع فقط، ويبقى في السيرة الذاتية |
| `end: null` | الوظيفة الحالية، تظهر "حتى الآن" / "Present" |
| `inProgress: true` | دراسة جارية، تظهر "قيد الدراسة" |
| `stats` → `auto: 'projects'` | يحسب عدد المشاريع أو الشهادات تلقائياً في الواجهة |
| `summary` | الملخص المهني في رأس السيرة الذاتية، وهو أهم فقرة لأنظمة ATS |
| `tools` | كلمات مفتاحية تقنية تظهر في السيرة فقط لرفع نسبة المطابقة |

نصوص الواجهة الثابتة، مثل عناوين الأقسام والأزرار وعناوين أقسام السيرة، موجودة في [`data/ui.js`](data/ui.js).

### ✅ التحقق قبل النشر

```bash
node scripts/validate-profile.mjs
```

يتأكد السكربت من عدم نسيان أي ترجمة، ومن صحة التواريخ، ومن وجود الحقول المطلوبة.
**يعمل تلقائياً في GitHub Actions قبل كل نشر.** إذا وجد خطأ يتوقف النشر ويبقى الموقع الحالي كما هو.

## 📄 السيرة الذاتية (ATS)

- **من الموقع:** زر **"تحميل السيرة / Download CV"** موجود في الشريط العلوي وفي الواجهة وفي أسفل الصفحة. يختار الزائر منه العربية أو الإنجليزية، ثم يحفظ الملف PDF من نافذة الطباعة.
- **Ctrl+P** في الموقع يطبع السيرة باللغة المعروضة حالياً.
- **رابط مباشر للمشاركة:**
  - الإنجليزية: `https://i3j.io/cv.html?lang=en`
  - العربية: `https://i3j.io/cv.html?lang=ar`
  - أضف `&print=1` لتُفتح نافذة الطباعة تلقائياً.

**لماذا هي متوافقة مع ATS؟** عمود واحد، ونص حقيقي قابل للنسخ (بلا صور أو أيقونات أو جداول)، وعناوين أقسام قياسية (Work Experience / الخبرة العملية …)، وتواريخ موحدة بأرقام لاتينية، ومعلومات التواصل داخل النص وليست في رأس الصفحة، وخطوط نظام قياسية، وحجم A4 في صفحتين.

> 💡 عند الحفظ PDF: اختر **Save as PDF / حفظ كـ PDF** وألغِ **Headers and footers / الرؤوس والتذييلات**.
> 💡 للتقديم على جهات دولية استخدم النسخة الإنجليزية. بعض أنظمة ATS العالمية تدعم العربية دعماً محدوداً.

## 🗂️ هيكل المشروع

```
index.html              ← هيكل الصفحة الرئيسية (المحتوى يُولَّد من البيانات)
cv.html                 ← صفحة السيرة الذاتية المستقلة (معاينة + طباعة + مشاركة)
data/profile.js         ← ✏️ كل المحتوى الشخصي (عدّل هنا)
data/ui.js              ← نصوص الواجهة وعناوين السيرة
js/core.js              ← أدوات مشتركة (الترجمة، التواريخ، اللغة)
js/site.js              ← عرض الموقع والتفاعلات
js/cv.js                ← مولّد السيرة الذاتية (ATS)
css/style.css           ← تصميم الموقع
css/cv.css              ← تصميم السيرة الذاتية (شاشة + طباعة)
scripts/validate-profile.mjs ← فحص البيانات
.github/workflows/static.yml ← فحص ثم نشر على GitHub Pages
```

## 💻 التشغيل محلياً

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

يمكن أيضاً فتح `index.html` مباشرة في المتصفح، فالموقع لا يحتاج أي أدوات بناء.
