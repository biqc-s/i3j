# i3j.io — الموقع الشخصي + السيرة الذاتية (ATS) + لوحة التحكم

موقع شخصي ثنائي اللغة (عربي / إنجليزي) لـ **سعيد أحمد جهاش**، منشور على [i3j.io](https://i3j.io) عبر GitHub Pages.
- **لوحة تحكم مجانية** تضيف وتعدّل منها كل المحتوى والصور، بدون أن تلمس الكود.
- **سيرة ذاتية متوافقة مع ATS** بالعربية أو الإنجليزية، يطبعها أي زائر أو يحفظها PDF.

---

## 🎛️ لوحة التحكم (Pages CMS)

### الإعداد لأول مرة (مرة واحدة فقط، 3 دقائق تقريباً)

1. ادخل إلى **[app.pagescms.org](https://app.pagescms.org)** واضغط **Sign in with GitHub**.
2. اضغط **Install the GitHub App**. اختر حسابك، ثم **Only select repositories**، ثم المستودع **`biqc-s/i3j`**، ثم **Install**.
3. ارجع إلى Pages CMS، واختر المستودع **i3j** والفرع **main**.

انتهى الإعداد. من الآن يمكنك فتح اللوحة مباشرة من:
**`https://i3j.io/admin`** (أو `https://app.pagescms.org/biqc-s/i3j/main`).

> 🔒 **الأمان:** لا يستطيع أحد غيرك التعديل. الدخول مرتبط بحسابك في GitHub، وصلاحية الكتابة على المستودع لك وحدك.

### الاستخدام اليومي

في القائمة الجانبية ستجد الأقسام التالية:

| القسم | ماذا تعدّل فيه |
|---|---|
| 👤 **الملف الشخصي** | الاسم، والصورة الشخصية، والتواصل، والملخص المهني، والألقاب المتحركة، والأرقام، وفقرات "من أنا"، واللغات |
| 💼 **الخبرات العملية** | الوظائف: المسمى، والجهة، والتواريخ، والإنجازات |
| 🚀 **المشاريع** | المشاريع مع صورة ورابط ووسوم |
| 🏆 **الجوائز والإنجازات** | الجوائز والتكريمات والفعاليات مع صور |
| 🎯 **المهارات والشهادات** | الكفاءات، والمهارات التقنية، والشهادات المهنية |
| 🎓 **التعليم** | الشهادات الأكاديمية |

**لإضافة عنصر:** افتح القسم، واضغط **Add an entry** أسفل القائمة، ثم املأ الحقول العربية والإنجليزية، ثم اضغط **Save**.
**للترتيب:** اسحب العنصر من المقبض ⋮⋮ بجانبه. الترتيب في اللوحة هو نفسه الترتيب في الموقع والسيرة، فاجعل الأحدث أولاً.
**للحذف:** اضغط أيقونة سلة المهملات بجانب العنصر، ثم **Save**.
**لرفع صورة:** في حقل الصورة اضغط **Upload** أو اسحب الصورة وأفلتها. تُحفظ الصور في مجلد `images/` داخل مستودعك.

### ماذا يحدث بعد الضغط على Save؟

```
Save في اللوحة
   ↓  تُحفظ التعديلات في المستودع (commit)
   ↓  GitHub Actions يفحص البيانات تلقائياً (ترجمات ناقصة؟ تواريخ خاطئة؟ صور مفقودة؟)
   ↓  إذا كان كل شيء سليماً → يُنشر الموقع
   ✅ خلال دقيقة تقريباً: الموقع + السيرة الذاتية (عربي/إنجليزي) محدَّثان
```

- إذا وجد الفحص **خطأ**، لا يُنشر شيء ويبقى الموقع الحالي سليماً. ستجد تفاصيل الخطأ في تبويب **Actions** في GitHub، فصحّحه من اللوحة واحفظ مرة أخرى.
- كل تعديل محفوظ في سجل GitHub، وتستطيع استرجاع أي نسخة سابقة.

### نصائح مهمة

| الحقل / الخيار | ملاحظة |
|---|---|
| **التواريخ** | بصيغة `YYYY-MM` مثل `2024-04`. اترك تاريخ النهاية فارغاً للوظيفة الحالية، فيظهر "حتى الآن" |
| **إخفاء من السيرة الذاتية** | يبقى العنصر في الموقع ولا يظهر في السيرة، وهذا مفيد لتقصير السيرة |
| **إخفاء من الموقع** | يبقى العنصر في السيرة ولا يظهر في الموقع |
| **الأيقونة** | اسم من [fontawesome.com/icons](https://fontawesome.com/icons) مثل `fa-trophy` |
| **النص المميز بالذهبي** | في فقرات "من أنا" اكتب `<strong>كلمة</strong>` |
| **الملخص المهني** | أهم فقرة لأنظمة ATS. اكتب فيه 3–4 أسطر فيها كلمات الوظيفة المستهدفة |
| **الصور** | يُفضَّل JPG أو WebP بعرض 1200px تقريباً وحجم أقل من 500KB، حتى يبقى الموقع سريعاً |
| **قسم فارغ** | إذا لم يكن في قسم "الإنجازات" أي عنصر يختفي تلقائياً من الموقع والقائمة، ويظهر عند أول إضافة |

## 📄 السيرة الذاتية (ATS)

- **من الموقع:** زر **"تحميل السيرة / Download CV"** موجود في الشريط العلوي وفي الواجهة وفي أسفل الصفحة. يختار الزائر منه العربية أو الإنجليزية، ثم **Save as PDF**.
- **Ctrl+P** في الموقع يطبع السيرة باللغة المعروضة حالياً.
- **رابط مباشر للمشاركة:** `https://i3j.io/cv.html?lang=en` أو `?lang=ar`. أضف `&print=1` لتُفتح نافذة الطباعة تلقائياً.

**لماذا هي متوافقة مع ATS؟** عمود واحد، ونص حقيقي قابل للنسخ (بلا صور أو جداول)، وعناوين أقسام قياسية، وتواريخ موحدة، ومعلومات التواصل داخل النص، وخطوط قياسية، وحجم A4.

> 💡 عند الحفظ PDF ألغِ **Headers and footers / الرؤوس والتذييلات**.
> 💡 للتقديم على جهات دولية استخدم النسخة الإنجليزية، فبعض أنظمة ATS العالمية تدعم العربية دعماً محدوداً.

## 🗂️ هيكل المشروع (للمطورين)

```
.pages.yml                   ← تعريف نماذج لوحة التحكم (Pages CMS)
data/content/*.json          ← كل المحتوى (تعدّله اللوحة)
images/                      ← الصور المرفوعة من اللوحة
data/ui.js                   ← نصوص الواجهة الثابتة وعناوين أقسام السيرة
index.html · cv.html         ← الصفحة الرئيسية وصفحة السيرة
admin/index.html             ← اختصار i3j.io/admin → لوحة التحكم
js/core.js                   ← تحميل المحتوى، والترجمة، والتواريخ
js/site.js · js/cv.js        ← عرض الموقع ومولّد السيرة
css/style.css · css/cv.css   ← التصميم
scripts/validate-profile.mjs ← فحص المحتوى قبل النشر
.github/workflows/static.yml ← فحص ثم نشر على GitHub Pages
```

### التشغيل محلياً

```bash
python3 -m http.server 8000      # ثم افتح http://localhost:8000
node scripts/validate-profile.mjs # فحص المحتوى
```

> الموقع يحمّل المحتوى من ملفات JSON، لذلك يحتاج خادماً محلياً كما في الأمر أعلاه، ولا يعمل بفتح `index.html` مباشرة من الملفات.
